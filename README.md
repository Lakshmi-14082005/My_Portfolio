> 
> 1. Go to: **[https://github.com/Lakshmi-14082005/My_Portfolio/settings/pages](https://github.com/Lakshmi-14082005/My_Portfolio/settings/pages)**
> 2. Under **Build and deployment** ➔ **Source**, select **GitHub Actions** (the included `.github/workflows/deploy.yml` workflow will automatically build and publish).
> 3. Alternatively, run `npm run deploy` in your terminal to publish to the `gh-pages` branch.
> 4. Once saved, GitHub will activate the live URL within 1 minute at:

## 💻 Local Development Setup

To run this portfolio locally:

```bash
# 1. Clone the repository
git clone https://github.com/Lakshmi-14082005/My_Portfolio.git
cd My_Portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle
npm run build

# 5. Deploy to GitHub Pages
npm run deploy
```
